# Судоку

Классическое судоку из GamePass отдельным сайтом: 6 уровней, поля 9×9/12×12/16×16, задача дня.

Внутри две игры: судоку и шашки (без онлайна, с ботом или вдвоём).

Сборка: `npm install && npm run build`, публикация — ветка `gh-pages` из `dist/`.
